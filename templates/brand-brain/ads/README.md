# ads/

Recent ad copy that actually ran, and any performance note you have on it.

The Performance Marketer in Session 6 reads this to extract a winners pattern: dominant format, hook style, copy length, the CTA verb you keep using, recurring phrases, and what is conspicuously missing from the set. It then either matches that pattern or breaks it on exactly one axis, so each new variant teaches you something.

Screenshots work. Pasted copy works better, because it is searchable.

Put your ad copy in `ad-copy-bank.md`.
