How this runs

Everything happens in the Claude Code desktop app, the Mac or Windows application. You will not open a terminal, apart from two lines of git clone in Session 0, and there is a ZIP fallback for that.

Three things you do over and over. Type / to see your roster. Watch the Tasks pane when a subagent runs. Click a file path in the chat to read what a teammate wrote.

Pro or Max plan

Claude Code does not run on the free tier.

Code tab

Not Chat, not Cowork. Skills only appear in Code.

Trust the folder

Untrusted folders do not load skills, so your roster stays empty.

Accept edits mode

Teammates write a lot of files. Manual mode will eat your session.

Glossary

CLAUDE.md

A file at your project root that Claude reads before every single thing it does, without being asked. Your brand, written down once.

Skill

A folder with a SKILL.md in it. A written job description. Claude loads it when what you asked matches its description, or you call it with a slash.

Subagent

A teammate that runs in its own context and hands back a summary. Used for jobs too big to fit in your session. You brief it once and it goes.

MCP

The standard that lets Claude talk to a live system. A connector is one already packaged, with a sign-in built in.

Connector

A first-party MCP server you add from the + menu. Google Drive, Gmail, GitHub and others. Click, authenticate, done.

Routine

A scheduled run inside the desktop app, in the Code tab sidebar. Runs on your machine, so the app must be open and the computer awake.

Index file

The short summary each teammate writes alongside its work. The Captain reads only these, which is what makes an orchestrator possible.

Parallel dispatch

One parent subagent spawning several children at once, each on a different angle, each with a clean context.

Default and Power

The two scopes every teammate offers. Default fits a Pro plan and a session slot. Power is for Max or take-home.

Safety flag

A note appended to a piece that failed a check. Teammates flag rather than silently fix, because a flagged piece you reject beats a takedown later.

Claim wall

The line in your CLAUDE.md past which no teammate may write a health or performance claim. FSSAI, CDSCO or Ayush, depending on your category.

Permission mode

Manual, Accept edits, Plan or Auto. Use Accept edits for the bootcamp, or you will spend the session clicking approve.
